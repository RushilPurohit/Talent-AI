# Talent AI – Explainable AI Hiring Intelligence

## Overview

Talent AI is an AI-powered recruitment intelligence platform designed to streamline the candidate screening process. The system analyzes resumes, evaluates candidate profiles against job requirements, and generates explainable candidate rankings to support faster and more informed hiring decisions.

The project leverages Artificial Intelligence and Explainable AI (XAI) principles to improve transparency, fairness, and efficiency in recruitment.

---

## Features

* AI-powered Resume Analysis
* Intelligent Candidate Ranking
* Explainable AI (XAI) based decision support
* Automated Candidate Evaluation
* Excel Report Generation
* User-friendly Interface
* Faster Hiring Process

## Installation

Clone the repository:

```bash
git clone https://github.com/premmahadik05-dev/Talent-AI.git
```

Move into the project directory:

```bash
cd Talent-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

---

## Use Case

1. Upload candidate resumes.
2. Provide job requirements.
3. AI evaluates each candidate.
4. Candidates are ranked based on suitability.
5. Download the generated ranking report.
